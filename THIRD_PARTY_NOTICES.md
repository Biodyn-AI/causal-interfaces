# Third-party rights and provenance

The MIT license covers original code only. CC BY 4.0 covers original saved
outputs, figures, manuscript text, and non-code documentation only. These
licenses do not change upstream rights.

The experiments use the upstream
[GPT-2 Small](https://huggingface.co/openai-community/gpt2) and
[GPT-2 Medium](https://huggingface.co/openai-community/gpt2-medium)
checkpoints distributed from Hugging Face. Model checkpoints are not included
in this repository. The Methods section and `docs/REPRODUCIBILITY.md` identify
the exact revisions and registered hashes required for fresh inference. The
checkpoints remain subject to their upstream model-card and license terms.

Python dependencies installed from package indexes retain their own licenses.
The Springer Nature LaTeX class and bibliography style in `paper/` are supplied
under their original template terms and are used only to build the manuscript.
