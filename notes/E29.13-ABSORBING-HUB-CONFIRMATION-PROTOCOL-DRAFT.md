# E29.13 absorbing-hub confirmation protocol — draft, not sealed

## Status and purpose

This is a response-blind draft. No E29.13 model response has been acquired, and
this document is not a registration seal.

E29.12 found post hoc that component 1, the layer-0 MLP residual update, almost
perfectly separated endpoint-level from sub-endpoint interventions on two older
panels. E29.13 asks whether that fixed explanation and its fixed prediction rule
survive on 12 wholly new lexical contexts and fresh cardinality-24 and
cardinality-32 masks. Passing would confirm a useful empirical decomposition:
one approximately absorbing component plus a smooth, predictable hub-absent
branch. It would not prove that the component is necessary, a formal Boolean
gate, or universal across models and tasks.

The sealed parents will be the E29.12 registration and results and the
exploratory absorbing-hub artifact with SHA-256
`fe354dad636617f4d37950cddd3565f89f5ee484789e525525c3d57b2e94e7b9`.
All post-hoc choices below become prospective only when the E29.13 registration
is sealed.

## Fixed model, intervention, and prompts

- Model: the exact GPT-2-medium float64 checkpoint, component map, attention
  implementation, batch size, residual-update semantics, and all-token patch
  scope inherited through the verified E29.12 parent.
- Components: 48 ordered residual updates, `(attention, mlp)` for each of 24
  layers.
- Candidate hub: component 1, `(layer 0, mlp)`.
- Matched star control: component 0, `(layer 0, attention)`.
- Prompts: 12 new induction contexts, three for each of the four inherited
  templates, using 96 words absent from all E29.8–E29.12 panels. The pinned
  tokenizer must validate one-token group words, aligned targets, and the exact
  registered token lengths before sealing.
- Response: the inherited donor-target-minus-base-target logit-margin change.
  The clean base-to-donor margin distance `A` remains a useful scale proxy, not
  a strict mathematical upper bound.

## Registered masks

The registration deterministically writes and hashes one closed protocol
artifact:

1. **Source fit table — 283 physical rows.** It is the de-duplicated union of
   the inherited 96 cardinality-1–3 rows, 32 cardinality-8 rows, 64
   cardinality-16 rows, all 48 singletons, all 47 hub-incident pairs, and all
   47 control-incident pairs. Named strata retain exact index maps into the
   shared table; overlap never causes a second model query.
2. **Held c24 — 48 rows.** Exactly 24 contain component 1 and 24 omit it.
3. **Held c32 — 48 rows.** Exactly 32 contain component 1 and 16 omit it,
   preserving its natural inclusion frequency at this cardinality.
4. **Diagnostics — two rows.** `all_components` is the registered c48 scale
   calibration. `all_minus_hub` is quarantined, report-only evidence.

Within each held hub stratum, incidence of every other component differs by at
most one. Held rows are disjoint from every registered E29.8–E29.12 mask, every
prior complement, every source row, and every source complement. The c24 panel
also contains no internal complement pair. Seeds, saturation constants,
reference-mask seeds, bootstrap seed, exact masks, source-stratum indices,
methods, scoring gates, and query schedule are all stored in the hashed
artifact.

## Acquisition and prediction custody

The fit acquisition is one combined 285-row call per context: 283 source rows,
the c48 calibration row, and the all-minus-hub row. The acquisition artifact may
contain all three response blocks, but the fitting API receives only source
responses and c48 calibration responses. It has no all-minus-hub response
argument. The all-minus-hub value cannot select a method, calibrate a method,
alter a prediction, or enter a hard gate.

After fit-label custody is hashed, all 11 registered methods produce both held
prediction tables. Their common artifact and preparation record must be hashed
before either held response table is acquired. The held acquisition then makes
one joint 96-row call containing both c24 and c32. It invokes no fitting or
scoring function and deserializes no raw fit/source response artifact. It does
load the frozen prediction artifact, including its permitted singleton and c48
calibration summaries, plus the sealed registration, protocol masks,
preparation record, and repeated clean checks.

Both acquisition stages repeat the inherited clean-prompt gates. Each stage is
charged 36 clean forward examples, giving 72 total. Every scientific artifact
is write-once and each stage requires the exact SHA-256 custody handoff from the
preceding stage.

The primary method is `gate_shape_c48_calibrated`. It fixes the hub identity,
uses the measured hub singleton for the hub-on branch, uses the sealed c48 row
with the frozen saturation curve to set the held-panel scale, and retains the
frozen MLP/additive ensemble's centered shape only in the hub-absent branch.
The frozen branch-shape multipliers are `1.0` at c24 and `0.85` at c32 for the
hub-absent branch and zero for the hub-on branch.

`gate_shape_clean_proxy_calibrated` replaces c48 calibration with the fixed
clean-proxy ratio and is a required secondary robustness test.
`gate_only_c48_calibrated` removes all within-branch shape and tests whether the
binary split alone is enough. The analytic hub-star and control-star methods
are secondary comparisons with no hard pass criterion.

## Hard gates

All thresholds apply separately at c24 and c32 unless explicitly described as
joint.

### Primary predictive gate: `gate_shape_c48_calibrated`

- pooled `R2 >= 0.80`;
- median context `R2 >= 0.75`;
- all 12 context-level R2 values positive;
- all four template-level R2 values positive;
- point MSE ratio strictly below 1 against both
  `additive_endpoint_cap_ridge10` and
  `mlp7_saturation_reanchored_c48` at both scales;
- at c32, the paired-bootstrap 95% upper MSE-ratio bound is strictly below 1
  against each baseline;
- for the equal-cell joint c24+c32 comparison, the paired-bootstrap 95% upper
  MSE-ratio bound is strictly below 1 against each baseline.

There is deliberately no separate c24 bootstrap-upper hard gate: development
power checks motivated the registered c32 and joint requirements. The exact
executable `SCORING_GATES` constant, not prose interpretation, is authoritative.
Every paired row bootstrap preserves the registered hub-on and hub-off counts;
context resampling stays within the four fixed template strata.

### Matched non-gated superiority gate

The primary method is also compared with
`capped_mlp_additive_ensemble_c48`, which uses the same MLP/additive score and
c48 calibration without the explicit hub decomposition. Superiority requires
point MSE ratio below `1` at both scales, a c32 bootstrap upper bound below `1`,
and a joint two-scale bootstrap upper bound below `1`. This is an aspirational
predictive-frontier claim, not a prerequisite for confirming the mechanistic
decomposition: retrospective ratios were near or above parity, so a failure is
expected to distinguish interpretability from raw predictive advantage.

### Hub-absent branch-shape gate

The primary method must also show that its within-branch shape contributes
information beyond the binary split. On hub-absent rows only:

- its point MSE divided by `gate_only_c48_calibrated` MSE is strictly below
  `0.80` at both c24 and c32;
- the equal-scale joint context-centered R2 is strictly positive; and
- the joint paired-bootstrap 95% upper MSE-ratio bound against gate-only is
  strictly below `1`.

This gate was chosen from response-blind power analysis on E29.11/E29.12. The
four retrospective per-scale MSE ratios were `0.557`, `0.386`, `0.448`, and
`0.439`; equal-scale joint hub-absent R2 was `0.373` and `0.473`. Per-scale
conditional metrics and per-context values are reported but not hard-gated.

### Mechanistic absorbing-hub gate

- component 1 ranks first among all 48 components by mean ceiling-classification
  accuracy; tied components receive rank 1, with uniqueness reported but not
  hard-gated;
- pooled ceiling accuracy is at least `0.98`;
- pooled ceiling F1 is at least `0.97`;
- mean hub-on response divided by clean endpoint lies in `[0.985, 1.01]`.

The ceiling label is `y >= 0.99 * A_context`. These conditions must hold at
both scales.

### Secondary gates

- `gate_shape_clean_proxy_calibrated`: pooled `R2 >= 0.75`, all 12 context R2
  values positive, and MSE no more than `1.15` times primary MSE at both scales.
- `gate_only_c48_calibrated`: pooled `R2 >= 0.75` and all 12 context R2 values
  positive at both scales.

Star comparisons and the all-minus-hub diagnostic are descriptive secondary
results and cannot rescue or fail the primary verdict.

## Interpretation rules

- A primary, hub-absent-shape, and mechanistic pass supports “approximately
  absorbing under this intervention distribution, with predictable residual
  structure when the hub is absent,” not logical necessity or a theorem.
- Passing the separate matched non-gated superiority gate additionally supports
  predictive-frontier advantage. Its failure does not erase a mechanistic
  decomposition pass and must be reported plainly.
- This is prospective mask/cardinality extrapolation after source interventions
  and within-context singleton/c48 calibration on the 12 new contexts. It is
  not zero-shot transfer to contexts unseen by the fitter.
- A predictive pass without the mechanistic gate supports a useful conditional
  surrogate but not the absorbing-hub interpretation.
- A clean-proxy pass shows that the c48 query is dispensable; a clean-proxy
  failure does not invalidate a primary c48-calibrated pass.
- The all-minus-hub result is disclosed regardless of direction but is never
  retroactively promoted to a gate.
- Any source, mask, prompt, gate, method, query-schedule, or custody deviation
  must be recorded explicitly and invalidates the undeviated confirmatory label.
